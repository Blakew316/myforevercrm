Employee gamification eligibility

Each active workspace employee can be controlled independently. Points/ranks, badges, and leaderboard visibility are separate. Turning one off never changes CRM access, sales ownership, commissions, role, or historical activity.

Leaderboard setup

Only people with Leaderboard Configuration permission can create, edit, hide, activate, deactivate, or change leaderboard scoring. Area, district and team boards are visible only to active members inside that branch; the company board is visible company-wide when active.

Points for this leaderboard — custom competition settings

Set how many points each recorded activity earns on this board. These weights change this board only; employee lifetime ranks continue to use workspace-wide rules.

Point rules

Set exactly how many points each verified CRM action awards. These rules are shared by every active leaderboard in this workspace. Changes are not live until you save them.

Custom point rules

Create workspace-specific scoring for activities that are not standard CRM events. Example: Every 50 doors knocked = 1 point. Record the completed quantity and Forever CRM calculates the points automatically.

Add a custom point rule

Examples: 50 doors knocked = 1 point, 10 outbound calls = 2 points, 5 customer reviews = 10 points.
