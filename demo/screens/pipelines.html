Rename common fields

Only common fields used by the selected template are shown. These names update with the preview, and you may customize them before applying.

Applying a template changes only this workspace. It is a starting point, not a locked layout. After applying it, workspace admins can rename pipeline stages and services, rename or hide fields, move fields into differently named sections, change dropdown choices, and add their own sections and properties. Existing contacts, appointments, activities, tasks, and saved values are retained. Old template-only properties are hidden, while your own custom properties stay available.
